# UI SFX Arcade cues

These four sounds come from the Arcade pack in
[`romainsimon/uisfx`](https://github.com/romainsimon/uisfx), commit
`2001f3dac2d1cf86ad99cbad5cef222c3a8b9082`:

- `focus`
- `select`
- `blocked`
- `long-press`

The upstream Ogg/Opus files were converted without trimming to 22,050 Hz,
16-bit, dual-mono PCM WAV for predictable playback on CardputerZero. The audio
is released under CC0-1.0; see `LICENSE-UISFX-AUDIO.txt`.
